# XDM New notices

XDM New is a macOS-focused modernization built from the historical Xtreme Download Manager source tree from [subhra74/xdm](https://github.com/subhra74/xdm), currently based on commit `7705a7e` in this repository.  The upstream project is published under GPL-2.0.

The Chrome helper project at [subhra74/xdm-helper-chrome](https://github.com/subhra74/xdm-helper-chrome) was reviewed as a reference for extension behavior.  It is licensed GPL-3.0.  XDM New's `macOS/chrome-extension` is an independently written loopback extension and does not contain that helper's native host or source files.

New macOS code in `macOS/` is released under GPL-2.0-or-later, consistent with the historical XDM base.  If code from the GPL-3.0 helper is incorporated in a future revision, that affected distribution must retain its GPL-3.0 notices and comply with GPL-3.0.
