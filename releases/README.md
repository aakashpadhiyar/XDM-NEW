# XDM New 0.1.0 macOS test build

`XDM-New-macOS-0.1.0.zip` contains `XDM New.app`, packaged from the source in this repository on macOS.

- SHA-256: `2a2b9192e50b250978c6a26a410b39d69bb96b54ef413f369ef6c801fb9a589d`
- Code signing: ad-hoc signed for local testing only; it is **not notarized** by Apple.
- Supported system: macOS with the system frameworks used by the included build.

To install, unzip the archive, drag `XDM New.app` to Applications (or another folder you control), then open it. If macOS blocks the initial run, use the app's context menu in Finder and choose **Open**, or allow it in **System Settings → Privacy & Security**.

The complete corresponding source, including the Chrome and Firefox extension sources, is in this repository. See the root `README.md` and `NOTICE.md` for build and license information.
